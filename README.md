# МЕРКЕ-ЕТ

Сайт мясоперерабатывающего комплекса ТОО «Мерке-ет комбинаты» (Меркенский район,
Жамбылская область, Казахстан).

## Статус

Концепт главной страницы. Статический сайт без сборки — открывается как есть.

```
index.html            главная страница
assets/css/style.css  стили и дизайн-токены
assets/img/           изображения (пока пусто, см. ниже)
docs/brief.md         ТЗ и контент от заказчика
docs/source/          исходный буклет (CorelDRAW)
```

## Локальный просмотр

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Изображения

Кадры для концепта сгенерированы через Higgsfield и пока подключены по прямым
ссылкам CDN. Перед продакшеном их нужно скачать в `assets/img/` и заменить пути
в `index.html` на локальные:

| Файл | Назначение |
| --- | --- |
| `hero-pasture.jpg` | первый экран — стадо на предгорьях Алатау |
| `plant-interior.jpg` | производственный цех |
| `beef-cuts.jpg` | карточка «Говядина» |
| `sheep-pasture.jpg` | карточка «Баранина» |
| `aerial-complex.jpg` | секция «Наше место» |
| `canned-jar.jpg` | тушёнка в стеклянной банке — ещё не сгенерирована |

Финальная цель — заменить сгенерированные кадры на реальные фотографии
производства, пастбищ и продукции.

## Дизайн-токены

Палитра и типографика продолжают фирменный стиль буклета:

- `--ink #0E2A1F` хвойный зелёный, `--lime #8CC63F` фирменный лайм
- `--cream #F4F0E6` кремовая бумага, `--meat #A8343A` мясной акцент
- Prata — заголовки, Manrope — текст, JetBrains Mono — цифры и технические подписи
