# МЕРКЕ-ЕТ

Сайт мясоперерабатывающего комплекса ТОО «Мерке-ет комбинаты» (Меркенский район,
Жамбылская область, Казахстан).

## Статус

Концепт главной страницы. Статический сайт без сборки — открывается как есть.

```
index.html            главная страница
assets/css/style.css  стили и дизайн-токены
assets/img/           изображения (пока пусто, см. ниже)
docs/brief.md         ТЗ и контент от заказчика
docs/source/          исходный буклет (CorelDRAW)
```

## Локальный просмотр

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Изображения

Кадры сгенерированы через Higgsfield и лежат в репозитории (`assets/img/`),
сайт не зависит от внешнего CDN. Список исходных ссылок — `assets/img/sources.txt`;
workflow «Скачать изображения в репозиторий» скачивает их, сжимает в JPEG
и коммитит. Чтобы заменить кадр, поправьте ссылку в sources.txt и запустите
workflow вручную.

Тот же workflow тянет и видео — список в `assets/video/sources.txt`. Ролики
сжимаются в H.264 без звука, шириной до 1600 px, с `+faststart` (начинают
играть без полной загрузки) и склеиваются в бесшовную петлю: первые 0,45 с
выбрасываются, а хвост растворяется в них, иначе на стыке «конец → начало»

Кадры, помеченные **фото комбината**, сделаны на самом комбинате. На сайте
стоят их отретушированные версии: исходники сняты на телефон — тёмные, с
жёлтым светом и мокрым полом, — поэтому каждый прогнали через модель, которая
сохраняет сцену (то же помещение, та же подвеска, то же количество туш, тот же
ракурс) и переосвещает её студийно. Это ретушь, а не документальный снимок:
пол и стены на сайте выглядят чище, чем на исходнике. Оригиналы лежат рядом в
`assets/img/original/` — если понадобится, кадр возвращается одной командой.

Эти файлы лежат в репозитории напрямую и в `sources.txt` не числятся, поэтому
workflow их не трогает. Остальные пока сгенерированы: нет реальных снимков разделанной
говядины, тушёнки, полуфабрикатов и пастбищ — их ещё ждём от заказчика.

## Сертификаты

Секция сертификатов показывает документы маленьким превью без увеличения:
просмотрщик и кнопка «Рассмотреть» убраны по просьбе заказчика. Защита
многослойная:

- исходные PDF в репозитории намеренно не хранятся;
- превью собраны в 760 px по длинной стороне и с водяным знаком — прочитать
  документ по такой копии нельзя;
- картинка подаётся CSS-фоном, а не тегом `<img>`: в контекстном меню нет
  «Сохранить изображение», кадр нельзя перетащить и нельзя открыть в новой
  вкладке, на iOS не всплывает «Сохранить фото»;
- контекстное меню и перетаскивание на превью дополнительно отключены скриптом.

Полностью запретить сохранение в вебе невозможно — скриншот сделает кто угодно.
Поэтому защита в том, что сохранять нечего: по кадру 760 px с водяным знаком
документ не подделать. Реквизиты каждого сертификата продублированы текстом
в карточке, оригиналы предприятие предоставляет по запросу.

## Языковые версии

Вариант D существует на трёх языках: `ranch.html` (русский, источник правды),
`ranch-en.html` и `ranch-kk.html`. Переводы собираются скриптом:

```bash
python3 build-i18n.py
```

Правки вносятся только в русскую версию, затем запускается скрипт — английская
и казахская пересобираются целиком. Словарь строк лежит в самом скрипте.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт при каждом пуше в ветку,
но первый запуск требует, чтобы владелец репозитория один раз включил Pages:
**Settings → Pages → Source: GitHub Actions**. Токену Actions не хватает прав
создать Pages-сайт самостоятельно (`Resource not accessible by integration`).
После включения сайт будет доступен на `https://kumanurmatov.github.io/merke-et/`.

## Дизайн-токены

Палитра и типографика продолжают фирменный стиль буклета:

- `--ink #0E2A1F` хвойный зелёный, `--lime #8CC63F` фирменный лайм
- `--cream #F4F0E6` кремовая бумага, `--meat #A8343A` мясной акцент
- Inter во всей типографике: 800 — заголовки, 400/500 — текст, 700 uppercase — надзаголовки и подписи
