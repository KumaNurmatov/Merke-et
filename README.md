# МЕРКЕ-ЕТ

Сайт мясоперерабатывающего комплекса ТОО «Мерке-ет комбинаты» (Меркенский район,
Жамбылская область, Казахстан).

## Статус

Концепт главной страницы. Статический сайт без сборки — открывается как есть.

```
index.html            главная страница
assets/css/style.css  стили и дизайн-токены
assets/img/           изображения (пока пусто, см. ниже)
docs/brief.md         ТЗ и контент от заказчика
docs/source/          исходный буклет (CorelDRAW)
```

## Локальный просмотр

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Изображения

Кадры сгенерированы через Higgsfield и лежат в репозитории (`assets/img/`),
сайт не зависит от внешнего CDN. Список исходных ссылок — `assets/img/sources.txt`;
workflow «Скачать изображения в репозиторий» скачивает их, сжимает в JPEG
и коммитит. Чтобы заменить кадр, поправьте ссылку в sources.txt и запустите
workflow вручную.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт при каждом пуше в ветку,
но первый запуск требует, чтобы владелец репозитория один раз включил Pages:
**Settings → Pages → Source: GitHub Actions**. Токену Actions не хватает прав
создать Pages-сайт самостоятельно (`Resource not accessible by integration`).
После включения сайт будет доступен на `https://kumanurmatov.github.io/merke-et/`.

## Дизайн-токены

Палитра и типографика продолжают фирменный стиль буклета:

- `--ink #0E2A1F` хвойный зелёный, `--lime #8CC63F` фирменный лайм
- `--cream #F4F0E6` кремовая бумага, `--meat #A8343A` мясной акцент
- Inter во всей типографике: 800 — заголовки, 400/500 — текст, 700 uppercase — надзаголовки и подписи
